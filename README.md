# Chalo privacy policy demo

A responsive, single-page React app built with Vite. Includes section navigation, active-section tracking, mobile navigation, and accessible page anchors.

## Run locally

```sh
npm install
npm run dev
```

Open the URL printed by Vite. To create a production build, run `npm run build`. To serve that build locally, run `npm run preview`.

The privacy policy is clearly marked sample content. Replace it with the operator’s verified policy and contact details before using it for an actual service. The demo does not collect or persist user data. Fonts are loaded from Google Fonts with system-font fallbacks.
